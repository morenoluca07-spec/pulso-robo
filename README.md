# Pulso: robô dos Sinais

A cada 30 minutos o GitHub roda a varredura de Sinais do app Pulso (`core/cloud/scan.ts`) e publica
`melhores.json` no GitHub Pages. O app lê esse arquivo para mostrar os Melhores mesmo com o PC desligado.

Dados públicos de mercado (Binance, brapi, Yahoo, Nasdaq, CVM). Estatística do passado, não recomendação de investimento.
Lógica de investidores portada da trader-skill (MIT, ver LICENSE-trader-skill).
